# Задачи по Stream API и лямбда-выражениям

## 📊 Уровень 1: Начальный (для знакомства с базовыми операциями)

### Задача: "Обработка списка студентов"

**Условие:**
Создайте класс `Student` с полями:
- `name` (String) - имя студента
- `age` (int) - возраст
- `grade` (double) - средний балл

Необходимо выполнить следующие операции используя Stream API:

1. Отфильтровать студентов старше 20 лет
2. Преобразовать имена в верхний регистр
3. Отсортировать по имени в алфавитном порядке
4. Вывести результат в консоль

**Пример входных данных:**
```java
List<Student> students = Arrays.asList(
    new Student("Alice", 22, 4.5),
    new Student("Bob", 19, 3.8),
    new Student("Charlie", 21, 4.2),
    new Student("Diana", 20, 4.7),
    new Student("Eve", 23, 3.9)
);
```

**Ожидаемый результат:**
```
ALICE
CHARLIE
EVE
```

## 🎯 Уровень 2: Средний (комбинация операций и коллекторов)

### Задача: "Анализ текстовых данных"

**Условие:**
Дан список строк (предложений). Необходимо:

1. Разбить все предложения на отдельные слова
2. Отфильтровать слова длиннее 3 символов
3. Привести все слова к нижнему регистру
4. Удалить дубликаты
5. Сгруппировать слова по первой букве
6. Для каждой группы посчитать количество слов
7. Вывести статистику в формате: "Буква: количество слов"

**Пример входных данных:**
```java
List<String> sentences = Arrays.asList(
    "Java is a programming language",
    "Stream API makes code more readable",
    "Lambda expressions are powerful",
    "Java streams process data efficiently"
);
```

**Ожидаемый результат (пример):**
```
a: 2
b: 1
c: 2
d: 1
e: 1
...
```

**Дополнительное задание:**
Вывести топ-3 самых частых первых букв

## 🚀 Уровень 3: Продвинутый (сложные преобразования и кастомные коллекторы)

### Задача: "Система анализа продаж"

**Условие:**
Создайте класс `Product` с полями:
- `name` (String) - название товара
- `category` (String) - категория
- `price` (double) - цена
- `quantity` (int) - количество проданных единиц

И класс `Sale` с полями:
- `productName` (String)
- `salesPerson` (String)
- `amount` (double)
- `date` (LocalDate)

Необходимо реализовать следующие методы:

1. **Найти топ-3 самых продаваемых товаров** (по количеству проданных единиц)
2. **Рассчитать общую выручку по каждой категории**
3. **Найти лучшего продавца месяца** (по сумме продаж за указанный месяц)
4. **Построить отчет по динамике продаж** - сумма продаж по дням/неделям
5. **Найти товары с самой высокой маржой** (разница между ценой и себестоимость)

**Пример структуры данных:**
```java
List<Product> products = Arrays.asList(
    new Product("Laptop", "Electronics", 1000.0, 50, 700.0),
    new Product("Phone", "Electronics", 500.0, 100, 300.0),
    new Product("Book", "Education", 20.0, 200, 10.0),
    new Product("Chair", "Furniture", 150.0, 80, 90.0)
);

List<Sale> sales = Arrays.asList(
    new Sale("Laptop", "John", 1000.0, LocalDate.of(2024, 1, 15)),
    new Sale("Phone", "John", 500.0, LocalDate.of(2024, 1, 16)),
    new Sale("Book", "Alice", 20.0, LocalDate.of(2024, 1, 15)),
    // ... больше данных
);
```

**Ожидаемые результаты:**
- Топ-3 товаров: [Book, Phone, Laptop]
- Выручка по категориям: {Electronics=150000, Education=4000, Furniture=12000}
- Лучший продавец января: John
- Динамика продаж: {2024-01-15=1020, 2024-01-16=500, ...}
- Товары с высокой маржой: [Book, Chair]

## 💡 Подсказки для ученика

### Для уровня 1:
- Используйте `filter()`, `map()`, `sorted()`, `forEach()`
- Помните про метод `compareTo()` для строк

### Для уровня 2:
- `flatMap()` для разбиения предложений на слова
- `Collectors.groupingBy()` для группировки
- `Collectors.counting()` для подсчета
- `Collectors.toMap()` или `Collectors.summarizingInt()`

### Для уровня 3:
- `Collectors.toMap()` для сложных агрегаций
- `Collectors.summingDouble()` для суммирования
- `Collectors.maxBy()` для поиска максимума
- Группировка по датам с `Collectors.groupingBy()`
- Сортировка с `Comparator.comparing()`
